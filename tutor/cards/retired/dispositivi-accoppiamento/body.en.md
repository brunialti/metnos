Open **Devices** in the instance console and select the user who will own the PC.

1. Select **I need to install on another PC**.
2. Give the device a short, recognizable name.
3. Generate the installation link and open it on the target Windows PC.
4. Download and run the self-contained client, then complete the pairing shown by the client.
5. Return to **Devices** and verify that the PC is listed as paired and active.

The link is temporary and intended for one pairing. If the PC is already listed, check the existing device before generating another link.
