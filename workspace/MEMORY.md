# MEMORY

> Memoria long-term di **fatti sul mondo**. Distinto dal mnestoma, che e'
> memoria relazionale di come funziona il sistema (cap. 13 Architettura).
> Una riga = un fatto. Niente storia, niente narrazione.

## Convenzioni

- Una riga = un fatto verificabile o stato dichiarato dall'utente.
- Datare i fatti volatili in formato ISO: `[2026-04-27]`.
- Niente segreti diretti qui dentro: solo riferimenti (es. "la chiave SSH
  e' in 1Password").
