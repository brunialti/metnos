# RM-0008: temporal arguments and mail verification

Status: implemented and released. The production release-45 exact 48-hour
mail check passed; release 46 retains that implementation. This record keeps
the original candidate evidence separate from production outcomes, recorded
in [the release ledger](rm0008-release-20260915.md).

## Implementation

- Shared timezone-aware arithmetic distinguishes calendar periods, instants
  and rolling durations. It validates dates, reversed ranges and ambiguous or
  nonexistent daylight-saving wall times. Native bounds preserve microseconds.
- Natural-language forms come from the versioned language resources. Legacy
  argument extraction also uses the shared calendar, not a separate UTC clock.
  A whole-period phrase is no longer copied into `since`: a lower endpoint is
  not an alias for a complete interval. Explicit endpoints remain unchanged.
- The common execution boundary handles schema-declared `date`, `date-time`
  and `time-window` scalars/arrays, plus the existing window arguments. This
  does not claim automatic traversal of arbitrary nested object schemas.
- Unfamiliar expressions may use one local `temporal.interpret` call with a
  six-second timeout, 240-token limit and constrained JSON grammar. The model
  translates meaning; deterministic code performs the arithmetic. Invented
  absolute dates are rejected. Unresolved meanings use the existing input
  form, not an additional authorization gate. Choices freeze their absolute
  dates and preserve valid array elements on resume.
- Mail uses IMAP INTERNALDATE before the Date header. SEARCH is an outward
  rounded coarse selection; exact receipt bounds are checked before limiting
  returned matches. BEFORE is exclusive. Fetching uses BODY.PEEK and a
  read-only mailbox selection. Candidate scanning remains bounded.
- The explicit unbounded `all` window passes without a model or selection
  form, including image/person search defaults. It is not a date/time instant,
  and a model interpretation may not use it to discard a temporal constraint.
