Roadmap

Here are the Metnos projects: what is already available, what we are finishing, and what is planned for the future. The newest projects appear first.

Each project shows when it was proposed and how far the work has progressed. Internal technical details are not published.

  1. 9 November 2026
    RM-012In progressProposed: 9 November 2026Delivery: started on 9 November 2026

    Disk space without useless history

    Metnos keeps what the active version uses, the previous version for recovery and whatever is still referenced; the rest is deleted by whoever produced it, right after a successful operation. Code copies received by the checks on new tools are already cleaned up with every update; for the photo index the check is under way.

  2. 20 September 2026
    RM-011Completed for GitHubProposed: 20 September 2026Delivery: GitHub verified on 23 September 2026

    A common rule for external services

    GitHub tools have names that describe what they do; the external service is specified through arguments. The GitHub migration is running and verified, and the old tools have been retired with their history preserved. Aligning Google Workspace remains separate work.

  3. 20 September 2026
    RM-010WaitingProposed: 20 September 2026Delivery: not started; proposal awaiting approval

    Choosing the right tool

    This project proposes consistent checks on the words used to describe tools, to reduce incorrect choices and assess imported tools too. The proposal is documented; its implementation phases await approval.

  4. 3 September 2026
    RM-009CompletedProposed: 3 September 2026Delivery: 9 November 2026

    Helping Metnos improve

    Metnos recognises what it cannot yet do and suggests it as a new tool. When the same missing capability is requested several times, even in different words, a proposal appears on the changes page; its score rises or falls with the data, and a rejected proposal does not come back. The person always decides, and an approved tool is used only after checks, review and consent. Tools cannot reach the administration keys. The cycle has been verified on real requests. Early proposals and automatic decisions will be considered only if the data justify them.

  5. 25 August 2026
    RM-008CompletedProposed: 25 August 2026Delivery: system running since 8 September 2026; closed on 9 November 2026

    Checks before using new tools

    New and updated Metnos tools must pass the same checks before they can be used. The system has been running since 8 September and has passed real-use tests. The controlled trial stage with automatic quarantine was cancelled: Metnos must work well regardless, and a newly generated tool becomes active only after checks, review and the person’s consent. Cleaning up history that is no longer used continues in RM-012.

  6. 24 August 2026
    RM-007CompletedProposed: 24 August 2026Delivery: 25 August 2026

    Translations checked before use

    When a tool’s description is translated, Metnos checks that it still describes the same function. The new version is used only after those checks, without quietly changing what the tool is allowed to do.

  7. 22 August 2026
    RM-006CompletedProposed: 22 August 2026Delivery: 23 August 2026

    Testing the whole request, including the result

    Metnos has been tested with requests in Italian and English, checking the results of actions as well as the replies. The planned cases passed. This does not guarantee that every possible request will be handled without errors.

  8. 21 August 2026
    RM-005CompletedProposed: 21 August 2026Delivery: 23 August 2026

    Metnos in your chosen language

    Messages, screens, tool instructions, and Tutor are adapted to the language chosen for Metnos. New translations are checked before they are activated, to avoid missing or inconsistent text.

  9. 17 August 2026
    RM-004CompletedProposed: 17 August 2026Delivery: 22 August 2026

    Long tasks without keeping the chat open

    LRE manages long tasks that qualify for this type of execution and saves their progress. You can follow them and find their results without keeping the chat open. After an interruption, the system checks whether and how to resume them.

  10. 23 July 2026
    RM-003CompletedProposed: 23 July 2026Delivery: 30 July 2026

    A guide inside Metnos

    Tutor answers questions about using Metnos, drawing on its documentation and available tools. It explains what you can do and how: it does not carry out actions for you.

  11. 23 July 2026
    RM-002CompletedProposed: 23 July 2026Delivery: 25 August 2026

    Consistent tool descriptions across languages

    Each tool has a description explaining what it does, what information it needs, and what it returns. Metnos checks that these details agree across languages and blocks versions that fail the checks.

  12. 23 July 2026
    RM-001WaitingProposed: 23 July 2026Delivery: not started

    Remembering preferences and habits

    The goal is to remember useful information on your computer so Metnos can help you better, keeping it separate from other users’ information. You will be able to review and delete what is remembered. This feature has not been built yet.

What the statuses mean. “Completed”: built and checked. “In progress”: work has started but is not finished. “Ready”: the design is defined, but the feature is not yet fully available. “Waiting”: work is not scheduled.
