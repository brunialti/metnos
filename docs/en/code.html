Code

public repository, boundaries, and checks

The code is available at github.com/brunialti/metnos under the AGPL-3.0 license. The repository contains the subset needed to install, run, and study Metnos: the runtime, admitted executors and manifests, device clients, installer, contract tests, and public technical documentation in Italian and English. The repository README and installer guide themselves remain English-only.

Relationship to an installed instance

The public repository is a deterministic export of the working tree, not a copy of an instance's data. Publication excludes private state, credentials, logs, internal reports, benchmarks, and private documentation; before a push, it also scans the final tree for secrets and identifying data. Each user's keys, accounts, preferences, and histories remain in the installation's data and configuration paths.

The software is pre-1.0: it is suitable for evaluation, self-hosted experimentation, and development, but interfaces and defaults may still change. The public README is English-only and states requirements, installation steps, and security boundaries.

Documentation and code

The Architecture guide documents component responsibilities, authority, failure conditions, and contracts. The domain reference and interface guide derive from runtime registries. On every publication, indexable pages also enter the Tutor's signed catalog; a documentation change invalidates that catalog and causes a complete candidate to be built before release.

To install Metnos, start with the installer guide. When reporting an issue, include the request, platform, observable result, and logs with secrets removed.
