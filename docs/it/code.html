Code

repository pubblico, confini e verifiche

Il codice è disponibile su github.com/brunialti/metnos con licenza AGPL-3.0. Il repository contiene il sottoinsieme necessario a installare, eseguire e studiare Metnos: runtime, executor e manifest ammessi, client per i dispositivi, programma di installazione, test di contratto e documentazione tecnica pubblica in italiano e inglese. Il README e la guida dell'installer nel repository sono invece soltanto in inglese.

Rapporto con l'istanza installata

Il repository pubblico è un export deterministico dell'albero di lavoro, non una copia dei dati di un'istanza. Il processo di pubblicazione esclude stato privato, credenziali, log, report interni, benchmark e documentazione riservata; prima del push controlla inoltre l'albero finale alla ricerca di segreti e dati identificativi. Le chiavi, gli account, le preferenze e le cronologie di ogni utente restano nei percorsi dati e configurazione dell'installazione.

Il software è ancora precedente alla versione 1.0: è adatto a valutazione, sperimentazione su un'installazione propria e sviluppo, ma interfacce e valori predefiniti possono ancora cambiare. Il README pubblico è in inglese e riporta requisiti, installazione e confini di sicurezza.

Documentazione e codice

La Guida all'architettura descrive responsabilità, autorità, condizioni di errore e contratti dei componenti. La Reference dei domini e la guida dell'interfaccia derivano dai registri del runtime. A ogni pubblicazione le pagine indicizzabili entrano anche nel catalogo firmato del Tutor; una modifica documentale invalida quel catalogo e ne fa costruire un candidato completo prima del rilascio.

Per installare Metnos, inizia dalla guida dell'installer. Per segnalare un problema, indica richiesta, piattaforma, risultato osservabile e log con i segreti rimossi.
