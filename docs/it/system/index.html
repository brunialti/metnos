Panoramica del sistema

La sezione Sistema spiega le componenti che l'amministratore può osservare o configurare dalla HTTP UI. Non è un inventario di dettagli interni: è una guida per capire che cosa governa ogni schermata, quali azioni sono consentite e quale verifica compiere dopo una modifica.

Osservare prima di agire

Le pagine amministrative distinguono informazioni che spesso vengono confuse: un processo può essere in esecuzione ma non sano; un servizio può essere sano ma intenzionalmente inattivo; una funzione può essere installata ma disabilitata. Allo stesso modo, associare un canale o un dispositivo non concede automaticamente ogni azione: identità, autonomia, policy ed executor restano controlli separati.

Una modifica affidabile segue sempre lo stesso ritmo: leggere lo stato effettivo, scegliere un comando disponibile nel catalogo chiuso, attendere la convergenza e rileggere salute e stato desiderato. La UI non espone un terminale generico e non trasforma valori arbitrari in comandi di sistema.

Accesso amministrativo. Le viste di questa sezione possono mostrare configurazioni operative e dati degli utenti. Vanno aperte soltanto tramite una sessione amministrativa affidabile; la documentazione pubblica non contiene segreti né valori personali.

Orientarsi nella HTTP UI

  1. Albero Sistema. Porta direttamente alle sei aree descritte in questa sezione.
  2. Quadro d'insieme. Riassume servizi installati, servizi in esecuzione e frequenza di aggiornamento.
  3. Scheda del componente. Distingue stato del processo, salute applicativa e stato desiderato.
  4. Funzione separata dal processo. LRE può avere un worker sano e restare intenzionalmente disattivato.
  5. Azioni circoscritte. La UI mostra soltanto i comandi ammessi per quel servizio e quello stato.

Schermata acquisita dalla HTTP UI reale. Gli eventuali valori identificativi nelle immagini di questa sezione sono sostituiti con esempi anonimi.
